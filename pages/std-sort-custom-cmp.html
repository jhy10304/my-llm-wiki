std::sort 與自訂比較函式 (Custom Comparator)

資料來源：raw/problems/uva-11321.md ｜ 時間複雜度：O(N log N) ｜ 最後更新：2026-11-15

核心摘要 (TL;DR)：
  • std::sort 採用內省排序（Introsort），平均與最差時間複雜度皆為 O(N log N)。
  • 比較函式 cmp(a, b) 回傳 true 代表 a 排在 b 前面，兩者相等時必須回傳 false。
C++ 負數取餘數邊界陷阱：
在 C++ 中，負奇數除以 2 的餘數為 -1（例如 -5 % 2 == -1）。判斷奇數時不可寫 x % 2 == 1，必須使用 x % 2 != 0！

標準實作範例（UVa 11321 多條件排序）

#include <algorithm>
using namespace std;

int M;

bool cmp(int a, int b) {
    // 1. 依照除以 M 的餘數由小到大排序（保留 C++ 負數餘數特性）
    if (a % M != b % M) {
        return a % M < b % M;
    }
    // 2. 餘數相同時，奇數優先於偶數
    bool a_odd = (a % 2 != 0);
    bool b_odd = (b % 2 != 0);
    if (a_odd != b_odd) {
        return a_odd;
    }
    // 3. 同為奇數則大到小；同為偶數則小到大
    return a_odd ? (a > b) : (a < b);
}
