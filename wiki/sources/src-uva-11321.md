# 來源摘要：UVa 11321 餘數與奇偶自訂排序

## 核心重點
1. **問題本質**：多條件優先級排序（Multi-key Sorting），最適合使用 C++ STL 的 [[std-sort-custom-cmp|std::sort 自訂比較函式]] 實作。
2. **關鍵陷阱**：
   - C++ 的 `%` 運算子對負數取餘數時會直接保留負號（例如 `-5 % 3 == -2`），正好符合本題定義，**不可**自行加 `+ M` 轉正。
   - 判斷奇數時，不可寫 `x % 2 == 1`（因為負奇數 `x % 2` 會等於 `-1`），必須寫 `x % 2 != 0` 或 `abs(x % 2) == 1`。
3. **陣列指標範圍**：若使用原生陣列 `int a[10005]`，`std::sort` 的結束指標必須傳入 `a + n`，不可傳入 `a[n]`（會導致型別編譯錯誤）。
