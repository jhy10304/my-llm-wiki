# 銀行調節表 (Bank Reconciliation)

銀行調節表用於核對「公司帳面現金餘額」與「銀行對帳單餘額」在特定月底日的差異，確保兩者調節後的**正確現金餘額**相等。

## 調節項目分類與分錄規則

| 調節方向 | 常見調節項目 | 是否需要做調整分錄？ |
| :--- | :--- | :--- |
| **銀行對帳單餘額加減項** | 在途存款（+）、未兌現支票（-）、銀行記帳錯誤（±） | **否**（等待時間差消除或通知銀行更正） |
| **公司帳面餘額加減項** | 代收票據與利息（+）、手續費（-）、NSF 退票（-）、**公司記帳錯誤（±）** | **是**（必須正式入帳修正公司現金餘額） |

## 實務案例應用：公司記帳錯誤更正
參考 [[src-terrell-bank-rec|Terrell Ltd. 案例]]，若公司現銷（Cash Sales）實際收現與帳面記載不符，假設帳面多記現金 $\$X$，則調節表上「公司帳面餘額」需減去 $\$X$，並編製以下更正分錄：

| 會計科目 | 借方 (Debit) | 貸方 (Credit) |
| :--- | :---: | :---: |
| 銷貨收入 (Sales Revenue) | $X$ | |
|  現金 (Cash) | | $X$ |
